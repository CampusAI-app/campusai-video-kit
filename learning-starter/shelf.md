# The shelf

Tools and parts we have found, and what we decided. Check here before searching. Add everything you
look at, including rejections, with the reason and the date. Recheck anything older than a couple of
months.

Verdicts: **using**, **watching** (promising, not tried or not decided), **rejected** (with why).

## Tools

| Tool | Verdict | Date | Notes |
|---|---|---|---|
| Raylight (raylight.app) | using | 2026-10-09 | Main editor. Free plan: 50 Claude calls a week and a badge on exports, so posting needs Hobby ($9/mo) or above |
| Remotion | using | 2026-10-09 | The `studio/` template. Free for companies with up to 3 employees, paid licence above that. Ask Jacob before posting a Remotion render |
| HyperFrames (heygen-com/hyperframes) | watching | 2026-10-09 | Free for any company (Apache 2.0), 59.5k stars, built for AI agents, 21 skills including a product launch video from a URL and a Remotion converter. Read on GitHub only, not tried yet |
| Motion Canvas, Revideo | watching | 2026-10-09 | Both free (MIT), code-to-video. Smaller and less set up for agents than HyperFrames |
| Cap (cap.so) | using | 2026-08-23 | Screen recording. Studio mode, every beautify option off |
| WhisperX (m-bain/whisperX) | using | 2026-09-19 | Word-level caption timing |
| ElevenLabs free tier | rejected for posting | 2026-08-28 | Non-commercial licence |
